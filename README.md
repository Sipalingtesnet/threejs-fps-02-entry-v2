**FROSTLINE** is a round-based tactical FPS set in an arctic research outpost. Defend the laboratory dome (Site A) and hangar (Site B) against enemy tactical squads across tense buy and live rounds.

## Features
- **Original Arctic Palette & Map ("Aurora Station")**: Snowdrifts, neon aurora light strips, service tunnels, runway sightlines, and laboratory structures.
- **Tactical Economy & Buy Phase**: Earn cash from kills and round wins/losses to purchase high-power weaponry (BLIZZARD-9 SMG, AURORA-50 Sniper).
- **Advanced Bot AI**: Patrol routes, line-of-sight engagement, and squad combat.
- **Immersive First-Person Controls**: WASD acceleration, crouching, sprinting, jump physics, and AABB collision.

## Controls
- **WASD**: Move
- **Shift**: Sprint
- **Control / C**: Crouch
- **Space**: Jump
- **Left Click**: Fire weapon
- **Right Click / Scope**: Aim down sights
- **B**: Buy Menu
- **1-4**: Switch weapons (NORD-7 Rifle, BLIZZARD-9 SMG, AURORA-50 Sniper, FROST-9 Pistol)

## Running Locally
```bash
node serve.ts --port 8123
```
